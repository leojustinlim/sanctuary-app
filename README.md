# Sanctuary V2.1 — Visual Identity and Illustration Alignment

A product-design refinement built on Sanctuary V2.0. **This development branch does not alter Greenhouse or the live main branch.**

## Changes
- Refined the story's editorial visual language: context appears as field notes, choice recall as a remembered moment, and lessons as paper-inspired reflection panels rather than generic left-border callouts.
- Revised the story-world introductory note styling, typography hierarchy, spacing, and mobile treatments.
- Adjusted Milo's cactus-body and facial-feature artwork leftward relative to the pot in all 30 `cactus-XX.svg` scenes; the pot and surrounding environment remain in place.
- Inspected the central flower and stem geometry in all 30 sunflower and 30 alpine illustrations; their centre geometry consistently uses x=480, so no blanket offset was applied.
- All 90 SVG illustrations remain on the branch.

## QA and limitations
- Static SVG structure and central-axis checks are not equivalent to a full visual/art-direction review. A rendered contact-sheet inspection across every image remains necessary for expressions, layering, emotional fidelity, and composition.
- Browser testing is also required (especially mobile Safari). This branch has not been merged into `main`.
- No changes to journaling choices, progression rules or user data format are intended.
